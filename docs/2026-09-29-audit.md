# Logical Lunge: devam kaydı ve doğrulama

## Amaç ve sınırlar

- Geliştirme hattı `native-bar`; `web-ui` desteklenen arayüz tercihi olarak korunur. `main` değiştirilmedi.
- Native bar Direct2D/DirectComposition ile çizilir. Diğer panellerin WebView2 dönüşümü sürüyor; Explorer yerine gerçek Windows kabuğu olma işi henüz bitmiş değil.

- Değişiklikler kaynak kodundadır. Çalışan `%ProgramFiles%/LogicalLunge` kurulumu bu düzeltmelerle güncellenmedi.
- Aktif kullanımda odak çalan ekran testleri ve ağır release derlemesi yapılmamalı. Çalışan bar/masaüstü değiştirilecekse önceden haber verilmeli.

## Ortak installer ve release

- Installer `native-bar` / `web-ui` seçtirir; açıklamalar mevcut mimariyi anlatır.
- Paket kimliği `EDITION` ile doğrulanır; varsayılan tercih kurulu edition'dır.
- Etiketler `vX.Y.Z-native-bar` ve `vX.Y.Z-web-ui`; paketler `LogicalLunge-<edition>-X.Y.Z.zip` ve aynı adın `.sha256` dosyasıdır.
- Installer ve çekirdek güncelleyici yalnızca seçilen edition'ın tamamlanmış, kararlı sürümlerini değerlendirir. Global `/releases/latest` kullanılmaz.
- Her edition'ın sürüm sırası bağımsızdır; sürüm tabanı `0.2.1` yapıldı. Böylece kurulu `0.2.0` düzeltme sürümünü görebilir.
- Action seçilen dalı derler; native, web veya ikisini yayımlayabilir. `main` kaynak alınmaz.
- “Geri” yanıtının onay sayılması, boş ek bileşen seçimi ve dil değişiminden sonra eski metinlerin kalması düzeltildi.
- Kurulumda eski araç yolları, başka programlar kullanabildiği için korunur. Bu oturumda eski WezTerm User PATH girdisi Program Files yoluna güncellendi; eski PATH yerel yedeğe yazıldı. AsenaScale kapandıktan sonra uygulama `%LOCALAPPDATA%/Programs/AsenaScale/AsenaScale.exe` yoluna taşındı; dosya hash’i doğrulandı, HKCU Run ve Başlat menüsü kısayolu güncellendi. AppData kimlik/cihaz dosyaları korundu. Eski `.glzr` bütünüyle `%LOCALAPPDATA%/LogicalLunge/legacy-backup/20260929/glzr` altına taşındı. Ortam değişikliği Windows’a bildirildi ve yeni PATH’in Program Files altındaki OpenConsole.exe dosyasını bulduğu doğrulandı. AsenaScale kapalı bırakıldı.

## Geçen kontroller

- Her iki edition için shell `cargo check -j 2 --offline`.
- Her iki edition için WM `cargo check -p wm -j 2 --offline`.
- C# çekirdek regresyonu: gerçek HTTP kabul/yönlendirme kodu, geçici loopback portu, geçersiz renk, yabancı origin, GET reddi, edition'a göre release seçimi. Çalışan çekirdeğe bağlanmaz ve geçerli renk kaydetmez.
- Installer/release: 13 kontrol; sürüm sırası, başka edition'a geçmeme, draft/eksik paket reddi, geri/onay, eski kural temizliği, özel dialog kuralını koruma ve tekrar çalıştırma.
- 120 tema kontrast örneği; geçersiz renk geri dönüşü.
- Pil veri alanları/süre birimi/eksik ölçüm; ileri-geri sarma, eski zaman çizelgesi, hız ve oturum değişimi.
- Saf Rust overlay politikası: ilişkisiz ve etkileşimli pencereler dışarıda kalır; masaüstü penceresi açılmaz.
- İki UI paketi esbuild ile üretildi. Playwright headless testinde renk düğmeleri, genel palet, başarısız kayıt, aydınlık mod ve web pil kartı geçti. Şimşeğin hap içinde merkezde olduğu geometriyle doğrulandı; test ekran görüntüleri incelendi.
- Sıcaklık aracı .NET Framework 4.8 referanslarıyla derlendi; çalıştırılmadı.
- `fish -n config/fish/config.fish` geçti.

1. Uygun masaüstü test zamanında yeni paketi kur: Chromium ve Gecko üzerinde video fullscreen giriş/çıkışı, tekrarlar, farklı DPI/monitör, Super+F, kenarlık ve düzen geri dönüşü. Genel politika testleri bütün tarayıcılarda gerçek ekran testi yapıldığı anlamına gelmez.

3. Gerçek dizüstünde şarja takma/çıkarma, sürücünün watt ve kalan süre sağlayıp sağlamadığı, native hover görseli ve AC/pil GPU davranışı denenmeli.
4. Action henüz GitHub üzerinde çalıştırılmadı; release yayımlanmadı. Kaynak testleri tam release paketi/temiz Windows VM kurulumunu karşılamaz. İki edition için ilk yayın, SHA doğrulaması, yükseltme ve kaldırma/rollback testi yapılmalı.
5. AsenaScale taşındı ve kapalı bırakıldı. Kullanıcı tekrar açtığında gerçek telefon/PTY bağlantısı sınanmalı. Eski konum geri alma yedeğinde; AGENTS.md ve CLAUDE.md aktif yolları gösterecek şekilde güncellendi.
6. Native arama/overview/panel dönüşümüne sonraki aşamada devam edilecek. `main`e aktarım bu çalışmanın parçası değil.

powershell -NoProfile -File tools/dev/installer-tests.ps1
powershell -NoProfile -File tools/dev/core-tests.ps1
node tools/dev/theme-tests.mjs
node tools/dev/bar-data-tests.mjs
rustc --edition 2021 --test tools/dev/window-policy-tests.rs -o build/tests/window-policy-tests.exe

UI testi için esbuild/React bağımlılıkları ve Playwright gerekir. Playwright başka bir çalışma ortamında kuruluysa `LL_PLAYWRIGHT` modül yolunu; tarayıcılar özel dizindeyse `PLAYWRIGHT_BROWSERS_PATH` yolunu gösterir. `node tools/dev/ui-tests.mjs <web-ui-checkout>` ayarları ve web barı izole taşıma katmanlarıyla sınar.

WinRT zaman çizelgesi semantiği: [Microsoft API belgesi](https://learn.microsoft.com/en-us/uwp/api/windows.media.control.globalsystemmediatransportcontrolssessiontimelineproperties). Pencere stilleri/sahipliği: [Microsoft pencere özellikleri](https://learn.microsoft.com/en-us/windows/win32/winmsg/window-features).

Belgede görünmez Unicode işaretleri elle temizlendi; gömülü metadata bulunmaz. Windows watermark temizleme aracı kurulu değil.
