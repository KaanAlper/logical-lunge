# 🎨 Logical Lunge: Web UI

This folder serves as a showcase for the **Web UI** edition of Logical Lunge.

> **Note:** The actual source code for this edition is actively developed on the [`web-ui` branch](https://github.com/KaanAlper/logical-lunge/tree/web-ui).

## Architecture
The Web UI edition offers the exact same powerful native core (C# + Rust Tiling), but delegates the visual components to web technologies.
- **Top Bar & Panels:** Rendered using **WebView2** and powered by **React**, HTML, and CSS.
- **Customizability:** Because the UI is just HTML/CSS, it is infinitely customizable. You can easily create your own themes, layout adjustments, and styles.
- **Try it instantly:** We have a live browser-based demo of this exact UI running right now.

👉 **[Try the Live Web Demo](https://logical-lunge-web-demo.vercel.app/)**
